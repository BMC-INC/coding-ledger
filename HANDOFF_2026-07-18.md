## Gotchas learned tonight

- iCloud Desktop makes cold `git log` minutes-slow (pack download). The repo
  cache (`repos` table) + `--git-timeout` exist because of this. Never
  re-walk Desktop; only `--rediscover` if repos moved.
- On macOS, `pkill -f "python3 ..."` does NOT match a running CPython (argv
  shows the framework binary). Kill by PID from `ps aux | grep "[p]ython"`.
