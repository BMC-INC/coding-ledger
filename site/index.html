Three questions no other tool answers together

What did your AI cost?

Token usage read straight from local Claude Code and Codex logs, priced at API list rates. API-equivalent value, what it would have cost, not what you paid on a subscription. Unknown models are labeled unpriced, never guessed.

What did it return?

Spend tied to shipped commits and merged PRs: cost per shipped commit, conversion rate per tool, unconverted spend, monthly trends, and your subscription ROI multiple.

How do you actually work?

Human-versus-AI attribution, total involved time verified against Screen Time, streaks, badges, and a shareable builder field report.

Real numbers, reproducible math

An actual Pro share card. Aggregate evidence only: no prompts, no code, no project names.

Hours you can defend

Screen time overlaps git, editor, and steering evidence, so it is an envelope, never blindly added. The formula is printed everywhere the number appears:

screen_hours   = allowlisted foreground seconds / 3600 (18h/day cap)
uncaptured     = max(0, screen_hours - max(human_evidence, shared_ai))
total_involved = max(human_evidence, shared_ai, screen_hours) + independent_ai
               = attributed_total + uncaptured

Uncaptured is the reading, reviewing, and debugging time in coding apps that produced no receipt. It credits to you, never to AI.

Private by construction

The ledger is a local SQLite file. It stores timestamps, counts, and aggregates. It never stores:

prompts or responses source code tool arguments or output credentials or API keys window titles or URLs anything phoned home
